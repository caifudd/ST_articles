# 财富咚咚电脑版怎么用：从授权登录到 K 线大窗，一篇讲完

先说这篇写给谁：已经装了、或者准备装「财富咚咚」电脑版的人。

它是什么、能解决什么问题，我在另一篇里写过，这篇只讲怎么用——包括几个藏在右键和悬停里、不点开根本发现不了的用法。按「第一次打开 → 认路 → 日常四件事 → 藏得深的用法 → 容易踩的坑」走一遍，大概十几分钟。

## 一、第一次打开，有三件事

1. 双击 exe 之后先出来一个小窗，写着「程序正在加载···」，几秒后主界面才出现。别急着双击第二遍。

2. 接着打开的是登录窗，不是主界面。软件要联网校验授权才能用，这一步绕不过去：

   - 想先试试：点 **「免费试用一天」**，一键开通，不用填任何东西。同一台电脑只能试用一次。
   - 已经买了：把授权码填进去点 **「登录」**，直接按回车也一样。
   - 客服要机器码：登录窗底部有 **「本机机器码」**，点旁边的 **「复制」** 发过去即可。
   - 换电脑：新电脑登录会提示已绑定，回旧电脑点 **「解绑本机」**，再去新电脑登录。

3. 登录失败会给出四种不同的提示，处置办法不一样：

   - **「连不上验证服务器」** → 先确认能上网；也可以打开「设置 → 线路选择」换一条线路并点「测速」，再点窗口上的 **「重试」**。
   - **「授权已到期」** → 到期了，续费或换一张新卡后重新登录。
   - **「账号已在其他设备登录」** → 这张卡正被别的电脑用着，在那边解绑，或者联系客服。
   - **「本机授权信息已失效」** → 先点「解绑本机」再重新登录；仍然不行就找客服。

## 二、五分钟认路

顶栏六个入口，从左到右是：**工作台、公告、风险榜、自选、行情、工具**。

工作台是默认页，也是日常待得最久的地方：左边是 ST 股列表，中间是这只票的公告，右边是这只票的 AI 解读，一屏三块。公告和自选点开是独立窗口，可以拖到副屏去，标题栏那颗图钉能让窗口一直浮在最上层。

底部状态栏从左到右：授权状态、最后更新时间、今日涨跌家数、五日涨跌家数；最右边两个链接是 **「使用教程」** 和 **「常见问题」**。

第一次用，照这五步走一遍就熟了：

1. 在工作台左上角搜一只票（代码、名称、拼音首字母都行），点一下；
2. 中间会出它的公告，右边会出它的 AI 解读；
3. 点一下名称格那颗 ☆，把它加进自选；
4. 右下角那个圆球是 AI 面板，点开随便问一句；
5. 关掉软件再打开，刚才那段对话还在——它是一只票一个会话。

## 三、日常四件事

### 第一件：扫全市场

工作台顶部那排筛选条是五组：**类型**（全部 / ST / `*ST`）、**新老**（全部 / 新ST / 老ST）、**排序**、**牛散**、**ST分类**。

ST分类这一组是「只显非标ST / 只显财务类ST / 只显结案类ST / 只显重整类ST / 只显已申请摘帽类」，加一个「全部」用来清掉筛选。点某一类的时候，排序会顺手切到这一类该看的字段上，不用再手动点一遍表头。

「牛散」下拉里，人名前面那个数字，是他在**全市场**的前十大流通股东名单里出现了几次（口径来自股东数据本身），不是本软件自选里的数量——这两个数不一样，我当初也弄混过。

两个搜索框：左上角那个搜个股，中间那个搜公告。有个省事的细节：搜完点中某只票，个股搜索框会**自动清空**；换到另一只票时，公告搜索框也会清空、分类重置为「全部」。

表头每一列都能点着排序，列与列之间的拖动柄可以把列宽拉开；「名称 / 代码」那一格是冻结的，横向滚多远它都在。

### 第二件：读公告

公告页是左边列表、右边正文，不用来回跳。顶部两个页签：**「ST最新公告」** 和 **「正股风险警示」**——后者是正股（本身还没戴帽）收到的风险警示类公告，从公告标题里筛出来的。

列表右上角有 **「按股票分组显示」**，开启后同一只票的公告归在一起，一眼能看出谁今天发了好几条。搜索框按关键词过滤，标题和 AI 摘要都在搜索范围内。

列表里点右键有三项：**问 AI · 查看个股 · 复制选中的文字**（没划字时是「复制标题和摘要」）。

右边正文卡上有一条工具行：**文字 / 原件**（用文字排版看，还是直接看公告原件）、**在浏览器打开**、**查看个股**、**复制正文**、**问 AI**、**清除**。

这里说句实话：每条公告旁边那个 AI 摘要，不是每条都有，按我们那天实测的口径大概三分之一。我现在习惯了——有摘要的先看，没有的就点开原文。

### 第三件：让 AI 读，也让它去查

AI 面板从好几个地方能唤起：右下角那个圆球、任意一只票上右键的「问 AI」、公告列表右键、公告正文上方的「问 AI」。

面板顶部可以在 **「本股 / 综合」** 之间切：本股是跟着当前选中的股票或公告提问；综合不限定个股，适合问规则和概念，比如「什么是路条」「预重整和重整差在哪」。

底部三个开关，默认值是：**深度思考开、联网搜索开、大白话关**。大白话关着的时候是正规模式——忠实原文、只做整理、不解释术语；打开才用大白话讲，并说明这件事意味着什么。我一般是先看正规那版，看不懂再开大白话。

它干的活有三种：把一条长公告读短；需要的时候自己去联网搜（并且把来源列出来，来源可以折叠）；需要这只票的数据时自己去查（现价、涨跌幅、为什么被 ST、有没有被处罚过）。

这里必须提前说清楚：**AI 用的是你自己申请的 DeepSeek 密钥**，提问费用从你自己的账号扣，软件不经手也不加价。不填这个 key，面板用不了。面板上会显示搜索次数和 token 用量，花了多少看得见。

一条回答下面有 **「复制」**，只有在出错或者你手动停止时才出现 **「重试」**。面板顶栏的 **「新对话」** 会清空这只票的聊天记录，它要点两次才会真的清，第二次按钮会变成「再点一次清空」。

### 第四件：记下来

自选里除了股票，还记着两样：**加入理由**（最多 150 字）和**加入时间**。理由这东西是写给几个月后的自己看的——当初为什么盯它、在等什么。

- **加进去**：点名称格的 ☆ 或者右键选「加入自选」，弹窗里写理由、选分到哪个组（可多选）；理由留空就记「手动添加」。
- **排序**：按住每行最左边的拖动柄拖，置顶只对本组生效。
- **改**：鼠标移到某一行，名称格下面会冒出三个按钮——**置顶（只对本组生效）· 所属分组 · 移出**。它们是悬停才出现的，很多人第一次找不到。
- **分组**：卡头的「分组管理」里新建；「默认」显示全部，不能改名或删除。

换电脑不想重加一遍，用卡头的 **「同步」**：先在旧电脑上复制那串 16 位同步码，到新电脑的同步窗里填进去点「使用」，自选、分组和加入理由就回来了。同步码跟授权码是两回事，换卡不影响自选。

## 四、几个藏得比较深的用法

这一段是我自己回头总结的，第一次用很容易漏掉：

- **右键菜单里的东西最多。** 在工作台某只票那一行点右键：问 AI、打开日线图、复制 ▸（股票名称 / 股票代码 / ST原因 / 公司名称 / 业绩信息 / 股东人数）、打开 ▸（司法拍卖、问董秘）、加入自选 / 移出自选。
- 软件其余地方点右键只有一项 **「复制」**（比如在公告正文里划一段字再右键）；输入框里保留系统自带的菜单。
- 自选页那三个小按钮是**悬停才出现**的，别以为没有。
- 表格里被截断的长文字，鼠标停上去能看到全文。
- **K 线大窗**从工作台小图右上角的 **「⤢ 大图」** 打开，也可以在某只票上右键选「打开日线图」。它是一扇独立窗口，开着的时候你在工作台切换股票，图会跟着换。
- K 线大窗的工具条有四档：**平移 / 标记 / 水平线 / 区间统计**，每档下面有一句操作提示。滚轮缩放（缩放锚点是光标底下那一根）、按住拖动平移、按住从左往右拖出区间统计、点一下打标记。
- 图上会给两样东西单独做记号：一是**有 AI 摘要的重要公告**，会在对应那根 K 线上打一个点，鼠标压上去看那天发了什么；二是从工作台带过来的**戴帽日**，会画一条水平线（取当天收盘价）。这两个是我最常用的。
- **「清除本股标记」** 跟「新对话」一样，要点两次。
- 提醒有三条路，口径一致——**只提醒重要公告**（重要 = 有 AI 摘要）：屏幕右下角弹小窗（软件最小化、被别的窗口挡住也照弹；最多 5 条，10 秒自动收起；点其中一条直接跳到那条公告）；在设置里填自己的飞书群机器人地址，一条公告推一张卡片；提示音只对重要公告响，关掉声音不影响浮层。
- 公告基本都是收盘后发的，所以提醒也集中在 **15:30 之后**到当天结束这段时间。

## 五、几个容易踩的坑

- **试用版只挡三处**：工作台的筛选与搜索、飞书群提醒、自选同步。其余都能用，包括 AI 面板和 K 线大窗。
- **不填 DeepSeek 的 key，AI 面板用不了**——这不是坏了。
- 它是绿色软件，双击就跑，不用配环境；依赖系统自带的 **WebView2** 组件，Win11 和大部分更新过的 Win10 都有，万一提示缺，去微软官网装一次那个小插件。
- 连不上服务器，先去「设置 → 线路选择」换一条线路测个速。
- 状态栏最右边就有 **「使用教程」** 和 **「常见问题」**，比我这里写得细。
